# Student Performance Data Visualization

##  Project Overview

This project analyzes student performance using Python and data visualization techniques. It studies student scores in **Math, Reading, and Writing** and compares them with factors such as parental education, lunch type, and test preparation.

##  Objectives

- Calculate the average score of each student.
- Analyze student performance based on parental education.
- Compare scores based on lunch type.
- Study the effect of test preparation on scores.
- Find the correlation between Math, Reading, and Writing scores.
- Display the results using easy-to-understand charts.

##  Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

##  Visualizations

The project includes:

- Bar Chart – Average Score by Parental Education and Lunch Type
- Box Plot – Score Variation Based on Test Preparation
- Pair Plot – Relationship between Math, Reading, and Writing Scores
- Heatmap – Correlation between subject scores

##  Dataset

The project uses a student performance dataset containing:

- Math Score
- Reading Score
- Writing Score
- Parental Level of Education
- Lunch Type
- Test Preparation Course

##  Analysis

An **average score** is calculated using the Math, Reading, and Writing scores. The project then groups and compares student performance based on parental education, lunch type, and test preparation.

##  How to Run

1. Download or clone this repository.
2. Open the Python file or Jupyter Notebook.
3. Make sure the dataset is available.
4. Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

5. Run the code.

##  Conclusion

This project provides a simple visualization-based analysis of student performance. It helps understand how different factors are related to students' academic scores.
